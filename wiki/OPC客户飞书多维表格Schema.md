# OPC 客户管理 — 飞书多维表格 Schema

> 用途:每个 OPC 客户建 1 个飞书多维表格,3 张表管理"客户信息 / 产品 / 宣传任务"
> 创建方式:飞书后台 → 多维表格 → 高级 → "从 JSON 创建" 或手动按字段创建

---

## 创建步骤(飞书后台)

1. 飞书 → 新建多维表格 → "空白表格"
2. 重命名为 `OPC-{客户编号}-2026`
3. 按上面 3 张表的字段,逐表创建
4. 客户信息表插入 1 行
5. 产品表插入 N 行(每 SKU)
6. 分享给团队成员(编辑权限)
7. **复制 table id**(用 API 自动化需要)
