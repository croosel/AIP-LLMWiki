## 设计规范

**配色系统：**

| 色彩 | HEX | 用途 |
|------|-----|------|
| Navy | `#0F172A` | 深色页面背景 |
| Navy Mid | `#1E293B` | 深色卡片背景 |
| Teal | `#0D9488` | 主强调色（标题、数据） |
| Teal Light | `#14B8A6` | 次强调色（副标题） |
| Orange | `#F97316` | 高亮/CTA/价格 |
| Coral | `#EF4444` | 风险/警告 |
| Gold | `#F59E0B` | 评分高亮 |
| Light | `#F8FAFC` | 浅色页面背景 |

**字体：** Georgia（标题/展示） + Calibri（正文） + Consolas（代码/数据）

**布局原则：** 深浅交替（Slide 1 深 → 2 浅 → 3 深…），卡片式信息容器，顶部色条装饰，统一底部信息栏

## 技术实现

**生成工具：** [pptxgenjs](https://gitbrent.github.io/PptxGenJS/)（Node.js PowerPoint 生成库）

**生成脚本：** `gen_pitch_deck.js`，约 530 行 JavaScript

**关键技术点：**
- `shadowFactory()` 函数避免 pptxgenjs 的可变对象陷阱（每次调用返回新 shadow 对象）
- 使用 `RECTANGLE`（非 `ROUNDED_RECTANGLE`）+ 顶部色条模拟圆角卡片效果
- 中文引号 `"..."` 与 JS 字符串定界符冲突，改用 `「...」`

**依赖：** `npm install pptxgenjs`
