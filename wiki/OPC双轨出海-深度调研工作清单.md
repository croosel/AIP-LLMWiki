## 调研说明

本工作清单基于对 OPC 双轨出海项目全部 11 个文件的深度阅读和依赖关系分析，覆盖商业规划、AI 架构、建站 SOP、案例分析、经验记录等所有维度。每个工作项均标注了依赖类型、执行方式和前置条件。

**两项重大更新**（2026-06-13）：

1. **建站技术路线变更**：从 独立站 平台改为自建站方案——使用自有域名 + 自主开发的 HTML/CSS/JS 静态站点，部署到静态托管平台（Vercel / Cloudflare Pages / Netlify）。这意味着完全掌控代码、数据、品牌呈现，不受任何第三方电商平台约束。

2. **质检 Agent 嵌入全流程**：独立质检总监（opc-qa-inspector）已部署，所有任务完成后必须通过质检 Agent 审计才能进入下游。流程变更为：定义任务目标 → 执行 → 质检 Agent 审计 → 通过/修订/回滚。

**执行类型说明**：
- **线性链（L）**：存在严格前后依赖，上游未完成则下游无法启动
- **可并行（P）**：与其他轨道无强依赖，可独立推进
- **周期性（C）**：按固定节奏重复执行的持续任务

**质检标记说明**：
- 每个任务完成后，标注 **[QA]** 表示需触发 opc-qa-inspector 审计
- 审计流程：任务启动前填写"任务目标文档"→ 任务执行 → 完成后提交审计 → 通过/修订/回滚

## 八、关键洞察与建议

### 洞察一：瓶颈不在执行，在输入

114 项建站任务中，需求收集阶段 AI 覆盖率仅 54%，而技术搭建阶段达 87%。**一旦客户素材到手，AI 几乎可以完成全部后续工作**。因此，T4-1（素材自助门户）和 T4-2（国际站数据抓取）是 ROI 最高的两项前置投入。

### 洞察二：自建站 = 更大的技术护城河

从 独立站 切换到自建站，短期增加了技术选型和组件库开发的工作量（T2-1 ~ T2-5 约 18-25 天），但换来的是完全的技术自主权——无平台佣金、无 API 限制、代码 100% 可迁移、SEO 无天花板。这与"三大核心风险"中的"平台下场风险"高度契合：我们自己的建站能力不依赖任何第三方平台。

### 洞察三：质检 Agent 是规模化的"质量保险"

首位客户建站增加了约 3 天的质检时间（5 个阶段关卡 × 0.5 天），但这笔投入换来的是：后续每个客户的建站质量都有自动化保障，CEO 审核比例可从 100% 逐步降至 5%。质检 Agent 是"建一个能审计系统的系统"。

### 洞察四：四条轨道的并行窗口

轨道一（AI 基础设施）、轨道三（获客蓄水）、轨道四 Phase 0-1（质检 Agent + 内容 Agent）完全可以在等待 PRE-1（首位客户确定）的窗口期内并行推进。

### 洞察五：三大核心风险的执行检查点

每个工作项在执行前，都应快速过一遍三大核心风险检查：
- **信任赤字**：这个动作是在积累信任还是消耗信任？有无真实案例支撑？
- **付费意愿**：定价是否匹配卖家心理账户？客户 30 天内能看到可感知价值吗？
- **平台下场**：这件事阿里自己做得到吗？我们在建立独立于阿里的能力吗？
