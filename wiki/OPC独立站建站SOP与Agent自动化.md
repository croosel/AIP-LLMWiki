# OPC 独立站建站 SOP 与 Agent 自动化分析

> 本页面记录 OPC 项目中独立站建站的完整 SOP、Agent（AI 编排工具）作为建站自动化工具的第一性原理分析，以及独立站建站总监 AI Agent 的职责定义。
> 关联项目文件：`子项目_独立站建站/` 目录下的三份文档。

---

## 为什么独立站建站是 OPC 的关键起点

独立站是[[OPC双轨出海商业模式]]中「第二增长曲线」的物理载体。没有独立站，双轨制就只有单轨。独立站建站也是 OPC 服务的第一个交付物——客户签约后最先看到成果的就是「我的独立站上线了」。

建站不是一次性工作，而是一个持续运营的过程：建站 → 填充内容 → SEO/GEO 优化 → 根据流量更新 → 季节性调整 → 产品上新下架。这就是为什么需要设立[[OPC-AI员工化架构]]中的「独立站建站总监」来统筹全生命周期。

## Agent 建站自动化 — 第一性原理结论

### 核心问题

Agent（AI 编排工具）是否适合做独立站建站自动化？

### 分析框架

将独立站建站拆解为五层原子工作：需求收集与素材准备、技术搭建（独立站）、内容填充、SEO/GEO 优化、持续运维。逐项评估 Agent 的能力。

### Agent 的能力匹配

| 能力 | 建站场景 | 评分 |
|------|---------|------|
| 代码生成（Liquid/HTML/CSS/JS/Python） | 主题定制、Schema.org 标记、自动化脚本 | ★★★★★ |
| 浏览器自动化（16 个工具） | 独立站 后台操作、产品上传、配置修改 | ★★★★★ |
| 内容生成（AI 文案 + SEO skill） | 产品描述、博客文章、Meta 标签、品牌故事 | ★★★★☆ |
| 图片生成（DALL-E/Gemini） | 产品场景图、Banner 图 | ★★★★☆ |
| 数据处理（Python + 文件操作） | 产品数据整理、批量处理、CSV 转换 | ★★★★★ |
| 定时任务（Cron） | 定期 SEO 检查、内容更新、流量报告 | ★★★★★ |
| API 调用（fetch + curl） | 独立站 Admin API、GSC API | ★★★★☆ |
| 研究分析（WebSearch + WebFetch） | 竞品分析、关键词研究、行业趋势 | ★★★★☆ |

### Agent 做不好的（需要其他工具补充）

高端品牌视觉设计（→ Canva 模板 + 按需设计师）、专业产品摄影（→ 客户提供 + AI 场景图补充）、复杂交互设计 UX（→ 参考成熟 独立站 主题）、面对面客户沟通（→ 人类 CEO）。

### 结论

**Agent 是最优的「建站编排中枢」（Orchestrator），但不是唯一的工具。** 建站是一项编排任务（orchestration task），不是单纯的编程或设计任务。它需要从非结构化输入（客户的零散图片、口头描述、国际站链接）生成结构化输出（完整的 独立站），并协调多个平台和工具。这恰好是 Agent 最强的能力组合：代码 + 浏览器自动化 + 内容生成 + 定时调度。

**推荐工具链分工：**

| 层级 | 工具 | Agent 的角色 |
|------|------|----------------|
| 编排层 | Agent | 总指挥：需求 → 拆解 → 调度 → 质检 |
| 内容层 | Agent + 营销/SEO skill | 直接执行 |
| 技术层 | Agent 代码 + 浏览器 | 直接执行 |
| 图片层 | DALL-E/Gemini + Canva | 协调执行 |
| 数据层 | Python + 定时任务 | 直接执行 |
| 设计层 | 独立站 主题 + 按需设计师 | 审核把关 |

### 规模化路径

第 1 个客户 3-5 天（建 SOP + 模板库），第 2-5 个每个 1-2 天（复用模板），第 6-20 个每个 0.5-1 天（高度自动化），第 21-100 个每个 2-4 小时（全自动化流水线 + 人工审核）。

## 独立站建站 SOP 概要

完整 SOP 详见项目文件 `02_独立站建站SOP-需求收集与全流程.md`，以下为五阶段概要：

### 阶段一：客户需求收集（Day 1-2）

收集五大类信息：基础商业信息（品牌名、品类、目标市场）、品牌资产（Logo、色板、品牌故事）、产品数据（产品清单、图片、参数、定价）、运营信息（库存管理、发货时效、退货政策 — 这些是客户通常不会主动提供的隐性需求）、创始人故事（30 分钟结构化访谈）。

### 阶段二：信息架构与设计（Day 2-3）

标准站点地图（首页 → 产品集合 → 关于 → 为什么选我们 → 博客 → FAQ → 法律页面）、页面设计决策清单（主题选择、Hero 风格、导航栏、CTA 文案）。

### 阶段三：技术搭建（Day 3-5）

独立站 配置 Checklist（账号 → 主题 → 导航 → 域名 → 支付 → 运费 → 结账）、产品上架自动化流程（国际站数据抓取 → AI 翻译优化 → 独立站 API 批量上传）、SEO/GEO 基础配置（GA4 + GSC + 结构化数据 + Meta 标签 + 速度优化）。

### 阶段四：内容填充与审核（Day 5-7）

按页面生成内容（AI 生成 70-95%），通过质量验收标准（品牌一致性、产品准确性、移动端体验、Lighthouse > 85、结账流程测试）。

### 阶段五：上线与交付（Day 7）

上线前 Checklist → 交付文档（登录信息、品牌素材包、SEO 矩阵、内容日历、维护指南）→ 独立站建站总监接管持续运维。

## 独立站建站总监的职责

独立站建站总监是[[OPC-AI员工化架构]]中直接向 CEO 汇报的 AI Agent，负责独立站的全生命周期管理。

**核心职责一：建站项目管理** — 执行建站 SOP，协调建站组、SEO/GEO 组、运维组，确保每个客户独立站 7 天内上线。

**核心职责二：SEO/GEO 策略与执行** — 制定 SEO 策略（关键词矩阵 + 内容日历），执行 GEO 优化（确保在 ChatGPT Search、Perplexity、Google AI Overview 中可见），每两周根据流量和排名做调整，根据季节和运营重点更新内容。

**核心职责三：持续运维与优化** — 每日监控网站可用性，每周生成流量报告，根据数据提出优化建议，管理产品上下架和促销活动。

**为什么 SEO/GEO 归建站总监而非运营总监？** SEO/GEO 是独立站的「基础设施」而非「运营活动」。它需要深入理解网站技术架构（Schema 标记、页面速度、内部链接）和内容策略（关键词布局、E-E-A-T 信号）。放在建站总监下确保 SEO/GEO 从建站第一天就嵌入，而非事后补救。

## 建站 SOP 任务 AI 员工化深度分析

对 SOP 中 114 项任务的逐项分析显示：54 项可 AI 全自主完成、33 项 AI 主导+人审、19 项人机协作、仅 8 项必须人类执行。CEO 每个客户只需投入约 3-5 小时做审核和沟通。

### 各阶段 AI 覆盖率

| SOP 阶段 | 总任务 | AI 全自主 | AI 主导+人审 | 人机协作 | 人类主导 | AI 覆盖率 |
|---------|--------|----------|-------------|---------|---------|----------|
| 需求收集 | 37 | 8 | 12 | 11 | 6 | **54%** |
| 信息架构 | 8 | 3 | 3 | 2 | 0 | **75%** |
| 技术搭建 | 31 | 22 | 6 | 2 | 1 | **87%** |
| 内容填充 | 18 | 8 | 7 | 3 | 0 | **83%** |
| 上线交付 | 14 | 9 | 3 | 1 | 1 | **82%** |
| 持续运维 | 6 | 4 | 2 | 0 | 0 | **92%** |
| **合计** | **114** | **54** | **33** | **19** | **8** | **76%** |

**关键洞察：** 需求收集阶段 AI 覆盖率最低（54%），因为本质是人际沟通。从阶段二开始飙升到 75-92%。**建站瓶颈不在执行，而在输入**。

### AI 员工任务分配矩阵（按角色分类）

**独立站建站总监（1 Agent）— 统筹层：** 建站项目计划生成、设计决策报告、质量验收报告、交付文档生成、建议零售价计算、目标客户画像推荐、品牌调性光谱生成。

**建站组（1-2 Agent）— 技术执行层：** 国际站产品数据抓取（ROI 最高：手动 3-5 天 → AI 30 分钟）、产品数据整理为 CSV、独立站 配置 13 项（账号→主题→导航→支付→运费→税率→结账→邮件模板）、主题安装+品牌定制（Liquid/CSS）、产品批量上架（独立站 API）、结构化数据代码（Schema.org）、OG/Hreflang/FAQ Schema、法律页面生成、站点地图生成、退货政策模板、域名查询。

**SEO/GEO 组（1 Agent）— 搜索可见性层：** 关键词研究（关键词矩阵）、Meta Title/Description 生成、竞品网站自动分析、GSC+Bing 验证+Sitemap 提交、SEO 博客文章生成（每两周一篇）、内容日历生成（3 个月）、促销日历生成（12 个月）、SEO 排名追踪（定时任务每两周）、内部链接优化、robots.txt+速度测试、行业参考网站推荐。

**文案组（2-3 Agent）— 内容生产层：** 英文产品标题生成、产品描述生成（FABE+SEO）、FABE 故事卡文案、品牌故事整理（访谈→800-1200 字文案）、首页 Hero 文案、CTA 按钮文案、邮件通知模板文案、全站拼写语法检查、访谈提纲定制。

**图片组（1-2 Agent）— 视觉层：** 产品白底图下载+抠图+裁切、产品场景图生成（DALL-E）、临时 Logo 生成、图片 ALT 标签生成、图片压缩+格式优化。

**运维组（1 Agent）— 持续运维层：** 网站可用性监控（每日定时）、GA4 流量周报（每周定时）、Lighthouse 性能测试、全站链接检查（404）、邮件通知测试、联系表单测试、社媒链接验证、GA4 实时数据验证、客户反馈分析、移动端测试（响应式截图）。

**视频组（1 Agent）— 视频层：** 产品短视频脚本生成、视频分镜建议、BGM 推荐。

### 必须由人类完成的 8 项任务

| 任务 | 原因 | 时间 |
|------|------|------|
| 客户初次沟通 | 建立人际信任 | 1-2h |
| 创始人故事访谈 | 情感共鸣 | 30min |
| 品牌 Logo 提供 | 客户自有资产 | 等待 |
| 库存管理方式确认 | 客户内部决策 | 5min |
| 客服联系方式确认 | 客户自有信息 | 5min |
| Hero 风格选择 | 品牌审美判断 | 10min |
| 产品页内容审核 | 最终质量把关 | 30-60min |
| 真实支付测试 | 需真实银行卡验证 | 10min |

**总人类时间：约 3-5 小时/客户**（分散在 7 天内）。

### 四个战略建议

1. **设计「客户素材自助门户」** — AI 引导客户自助提交素材并自动检查完整性，解决输入瓶颈
2. **将国际站数据抓取独立产品化** — 不仅服务建站客户，还可作为单独增值服务
3. **建站后立即配置 SEO/GEO 定时任务** — 形成「永不停歇的 SEO 引擎」
4. **开发「建站质量自动验收系统」** — AI 跑完 18 项检查输出绿/黄/红报告
